# Фабрика браузерных HTML5-игр

Репозиторий хранит общие правила производства и эталон одного игрового проекта. Он ориентирован прежде всего на Yandex Games, но предусматривает адаптеры VK Mini Apps, обычного Web и Android/RuStore.

## Структура

- `AGENTS.md` — постоянные инструкции, роли, критерии передачи работы и fix-цикл.
- `FACTORY_WORKFLOW.md` — жизненный цикл, зависимости и контрольные точки.
- `factory-template/` — копируемый эталон проекта без конкретной механики.
- `games/` — будущие изолированные игры.
- `scripts/create-game.sh` — безопасное создание `games/<game-slug>/` из шаблона.
- `scripts/validate-factory.sh` — проверка полноты фабрики.

## Для агента

По запросу «Создай новую игру `<slug>` из factory template» выполни из корня:

```bash
./scripts/create-game.sh <slug>
```

После этого работай только в `games/<slug>/`, заполняя документы до реализации. Пользователю не требуется копировать файлы вручную.

Текущий репозиторий содержит только фабрику: конкретная игра, SDK платформ и финальный HTML намеренно не созданы.

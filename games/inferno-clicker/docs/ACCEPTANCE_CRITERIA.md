# Acceptance Criteria — «Зажги»

Это исполнимый stop contract и единственный источник статуса DONE для `inferno-clicker`. Новый animation/seal/audio corrective cycle отменяет прежний статичный visual/audio/balance baseline. Evidence exact build `0.1.0+dd459e6fed2e` остаётся историческим и может подтверждать только явно сохранённые неизменные строки; его screenshots/reports не подтверждают `NC-A`–`NC-E` или новые motion/listening gates.

- Новый corrective exact Build ID должен быть создан из идентифицированного clean commit после реализации всех новых требований. До этого все строки нового цикла имеют статус `NOT RUN`.
- QA reports: `reports/QA_REPORT.md`, `reports/VISUAL_QA_REPORT.md`, `reports/PERFORMANCE_REPORT.md`.
- Исторический automated/browser run не переводит ни одну новую animation/seal/audio/motion строку в PASS. Новый exact-build run и evidence обязательны после реализации всех `NC-A1`–`NC-E4`.
- Перед release допустимы статусы `PASS`, `FAIL`, `BLOCKED`, `N/A — причина`. Каждый `PASS` обязан ссылаться на evidence от exact Build ID; `N/A` требует письменного обоснования Reviewer.
- DONE разрешён только когда retained CG-01/CG-02, все `NC-A1`–`NC-E4` и все применимые строки восьми групп ниже имеют `PASS`, открытых Critical = 0 и High = 0, QA report завершён, regression подтверждён, а production build и ZIP воспроизводимы из одного идентифицированного commit.
- VK Mini Apps и Android/RuStore не входят в scope первой реализации и не являются строками этого stop contract; заявить их поддержку можно только отдельным change request.

### Resolved specification decisions and remaining evidence blockers

- Product/Game Design/Monetization/Platform согласованы: stages 1–4 доступны без provider, heat lock равен 559, current Generic Web/dev использует явно маркированный test provider, а Yandex release — только Yandex SDK. До implementation fixtures этот контракт остаётся `NOT RUN`, но specification conflict закрыт.
- Art/Asset/Architecture согласованы на authored atlas clips и запрет static-cutout/static-card fallback; working candidate содержит production frames/hashes, но exact-build motion evidence ещё отсутствует.
- Audio/Architecture согласованы на `acceptedHeatBurst`, 120-ms aggregation, 180-ms cooldown и ≤2 затухающих fan voices; working candidate содержит attributed OGG/MP3 sources, но двухслушательское evidence ещё отсутствует.
- Старый `canonicalNoAdTraceV2` более не является progression acceptance. V3 fixtures и hashes входят в working candidate и проходят 60/30/15 FPS; формальный PASS требует clean exact-build report.
